# 填写学校下发的 docx 表格（实测要点）

适用于政府/学校下发的表格类 docx（采集表、申请表、评议表），同样适用于 xlsx 报表。
配套脚本：`scripts/docx_form_fill.py`（dump / 规范 w:sym / 整段重写 / 跨 run 替换 / 按列号写单元格）。

## 运行脚本

Hermes 的 venv 里没有 pip，不要往它里面装包，也不要为装包改环境。用 uv 的一次性依赖：

```bash
uv run --with python-docx python fill.py in.docx out.docx
uv run --with openpyxl python read.py book.xlsx
uv run --with fonttools python glyphs.py
```

## 结构探查

- 先用 `read_file` 读 docx/pdf/xlsx（自动抽取文本）拿到全貌，再决定要改哪些字段。
- 再跑 dump 脚本按 `[T表号R行C列] '文本'` 打印段落与单元格，确认每个目标值的坐标，然后才写替换脚本。
  不要凭抽取文本的行号盲改 `word/document.xml` 字符串。
- **行/列号有两种，用错会静默写歪**：
  - `row.cells` 是**原始网格列号**——合并区域里每一列都返回同一个单元格（同一 `_tc`）。
    写值必须用原始列号（`table.rows[r].cells[c]`），合并格会自动落到正确的格上。
  - 删掉重复 `_tc` 后的**去重序号只用于打印**，不能当写值坐标：去重后序号与网格列号错位，
    实测会把姓名写进“民族”格、身份证号写进“学号”格，且脚本不报错。
- python-docx 的 `cell.text` **不返回 `w:sym` 符号**。表格里的复选框、下划线占位往往是 `w:sym`，所以
  “用文本判断哪个选项被勾了”会全部落空——必须按下面的符号码位处理。

## 复选框是 w:sym 符号，不是文字

中文公文表格的方框常用 Wingdings 2 插入。用 fontTools 读字形名即可确定码位含义（实测 WINGDNG2.TTF）：

| 码位 | 字形名 | 含义 |
| --- | --- | --- |
| `00A3` / `F0A3` | `box1` | 空方框 |
| `0052` | `boxcheck` | 已勾选的方框 |
| `0050` | `check` | 对勾 |
| `009F` | `square1` | 方块 |

查法：

```python
from fontTools.ttLib import TTFont
f = TTFont("C:/Windows/Fonts/WINGDNG2.TTF")
m = f['cmap'].tables[0].cmap          # 符号字体没有 best cmap，要取 tables[0]
print(m.get(0xA3), m.get(0x52))        # box1 / boxcheck
```

Wingdings 是符号字体，`getBestCmap()` 返回 `None`，PIL 按字符直接渲染只会拿到 `.notdef`（一个窄长方形），
用它判断字形会得出错误结论——查字形名，不要靠渲染猜。**也别为了“看看原样长什么样”去截图验证**：
这一步对填表结果没有影响，用户会直接打断要求讲流程。

**勾选一律显式写，不靠推断**：模板出厂状态里每个选项对的勾/空并不符合直觉（实测每个“是，否”对
都长成“空框 是，勾框 否”），所以“没动过的那一对”会被读成已选“否”。做法是：
先把目标文档里所有 `w:sym` 按码位换成字面字符 `□` / `☑`（江苏省官方采集表本身就用字面字符），
然后用文本替换逐对显式写成 `☑是，□否` / `□是，☑否`——凡是要表态的选项对都必须写全，不留原样。

## 定点替换

- **键与段落文本都要 `strip()` 后比较**：Word 的 run 里常带行尾空格（“姓名：   居民身份证号码：…”），
  拿带尾空格的原文当键会整批不命中，且失败是静默的。实测一次未命中 7 个字段，全是空格差异。
- **跨 run 替换**：先把段落内所有 run 的原始 `(start, end)` 偏移固化成列表，再动手改 `run.text`。
  边改边算偏移，会因为第一个 run 长度变化而让后续 run 的区间全部错位。
- 只改值不改结构：年级、年龄、区间勾选、金额、日期这类等长替换最安全；整句改写时把新文本写进第一个受影响 run，清空其余部分。
  按“整段重写”的方式填值（保留首个 run 的格式即可）比逐字数替换更稳，也更好回读。
- 空白格里没有 run 时（新建单元格）要按段落标记 `w:pPr/w:rPr` 复制字体再建 run，否则新值会掉成默认字体。
- 改完必须**回读验证**：再跑一次 dump 确认新值出现、旧值消失；替换脚本要打印每条的命中数并要求“未命中: 无”，
  命中数为 0 就是坐标或键写错了。最后把结果文件路径报给用户。
