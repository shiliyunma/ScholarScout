# 校招笔试准备：情报抓取 → 全覆盖题库

> 触发：“去搜索 `<公司>` 笔试的相关信息，把资料放到 `<目录>`，随后总结提炼，去寻找类似的题型，尽可能覆盖全面”。
> 产出物是隔天（甚至当晚）就要上考场的，**先保时效、再求全**；抓不到的内容要明写“没拿到”，绝不用推测填空。

## 一、目录形状（开工先建）

```
4-刷题\<公司>-测评-MMDD\
├─ README-资料说明.md            ← 索引 + 文件清单 + 三条最关键结论
├─ 模拟题-<方向>-全覆盖-MMDD.md   ← 题型地图 + 分模块题 + 时间分配表 + 考场战术
└─ 相关信息\
   ├─ 01-<公司>-笔面真题与题型.md  ← 情报汇总（每条带出处与原话）
   ├─ 02-官方要求与测评规则摘要.md  ← 邀请邮件/短信里的硬要求
   ├─ raw-<站点>-<关键词>.html     ← 原始抓取（失败项也留，可回溯）
   └─ <平台>帖-<日期><主题>.md     ← 面经/真题帖原文
```

用户会**边聊边往 `相关信息\` 里贴截图**（Snipaste 默认命名）—— 完工前 `search_files` 列一遍目录，把新图读进来并归类。

## 二、抓取（中文源的可靠路径）

**首选牛客（一手面经最多，且搜索页可直接抓）**
```bash
curl -sS -L --max-time 40 -A "Mozilla/5.0 (Windows NT 10.0; Win64; x64) Chrome/126.0 Safari/537.36" \
  "https://www.nowcoder.com/search?type=post&query=<URL编码关键词>"    # 翻页加 &page=2；换范围 type=all
```
去 `<script>` / `<style>` 与全部标签后取纯文本 —— 结果列表里就带**考生原话**（题型、题量、难度、面试原题）。
帖子正文：从搜索页 HTML `re.findall(r'href="(/discuss/\d+)"')` 取出路径，逐个抓 `https://www.nowcoder.com<path>`。

**官方原文（公众号）**：`mp.weixin.qq.com/s/…` 用 **MicroMessenger UA** 的 `curl` 能直接拿正文（详见 `poster-screenshot-intel-extraction`）。

**搜索引擎只用来找方向，不要用来查中文短词**：公司名里的单字会被当字典条目（实测返回一堆“招”字释义），而站内搜索直接命中。

**原始 HTML 一律落盘**到 `相关信息\raw-*.html`；失败的抓取也要落盘 + 在汇总里写明“此路无效”，不然后续会话会重走一遍。

## 三、`01-汇总` 必须有的四块

1. **笔试形态**：题量 / 题型 / 难度，**每条都带考生原话 + 出处 URL**（如「选择题 15 题，经典八股为主」「就一道算法题，贪心，5 分钟写好，很简单」）—— 原话既是证据，也是给用户的定心丸。
2. **逐项考点**：把选择题覆盖的科目、编程题的类型列全；**特别注意公司特色题型**（代码填空、看代码写输出、ACM 模式、高精度/大数、SQL 手写、问答）。
3. **同批次面试原题**：面经能反推笔试深度与后续环节（八股清单 + 手撕题名 + 流程 timeline：投递→笔试→几面→资格审阅）。
4. **复习优先级表**：P0/P1/P2，每条附“证据”列（哪句原话支撑它）。

## 四、题库文件的形状

- 开篇 **题型地图表**：模块 → 出现形式 → 份量 → 依据。
- 分模块出题；**每题标 `🔴 真题`（有出处）/ `⚪ 同类题`（自拟补齐）**，混标会让他把自拟题当真题背。
- 给**答案要点 / 可运行代码**，不写教科书长文；手撕题给完整 Java 代码（这类最容易“想得起思路、写不出代码”）。
- 公司特色题型**单独成节**并给可复制的模板（如 BigDecimal 精度与舍入、Stream 方法名带括号、ACM 输入输出骨架）。
- SQL 题要真的给可执行语句（多表联查 / 分组聚合 / 取每组最新 / 高于均值），别只描述思路。
- 结尾：**时间分配表**（从“现在”按小时排到开考）+ **考场战术**（先做哪块、输出格式、跳题策略）。

## 五、`02-官方要求` 与收尾

- 从邀请邮件/短信抽硬要求：设备（仅 PC / 浏览器版本 / 网速）、监控（双机位、摄像头、**草稿纸须在拍摄区内**）、页面跳出次数限制、**选卷＝选岗**（选完不可换）、提前试登录时间、客服电话。
- 回执里**只报最容易临时缺的那一两件**（例：手机支架、摄像头、第二台机器），不要整段复述规则。
