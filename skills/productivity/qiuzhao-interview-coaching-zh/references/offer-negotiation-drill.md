# 谈薪演练手册（校招 / 大浩）

配套：SKILL.md 铁律十（演练协议）、铁律八（HR 面口径）。
公司薪资带与税后计算来自 `china-campus-recruiting-research`（`references/salary-and-takehome-research.md`、`scripts/takehome_calc.py`）。

## 0. 三条铁律

1. **薪资带是对方的成本区间，不是他的报价单。** 把 band 原样报回给 HR = 替对方确认“下限也能招到人”。
2. **报数只报一个点，不报区间。** 区间会被读成下限；报 band 的上部（约 70–75%），给自己留 3–4K 的让步走廊。
3. **月薪谈不动就换条款**，按值排序：公积金比例与基数 > 补贴是否随月发 > 评级复核 > 转正时间 > 签字费。

## 1. 判分表（每维 0–2）

| 维度 | 2 分 | 0 分 |
|---|---|---|
| 锚点 | 报一个点、且在带的上部 | 给区间，或直接报到下限 |
| 先问后答 | 反问定档规则 / 让 HR 先说 | 一被问就报数 |
| 依据 | 项目经历 + 薪数结构 | 空要、卖惨、拿同学比 |
| 不暴露底价 | 全程不出现“最低”“都能接受” | 报出底价 |
| 换条款 | 被压价时转向非薪资项 | 在月薪上硬磨 |

**判分必须换算成年薪差额**（算例见 §5）——分数与钱一起给，他才记得住。

## 2. 陷阱问题 → 应对（HR 话术逐条）

| HR 说 | 陷阱 | 应对原话 |
|---|---|---|
| “我们范围 14–22K，你期望多少？” | 用区间换你的数 | 先问：“这个带是按面试评级定档，还是本科有固定档？”再报**一个点**（20K） |
| “直接说个具体数，**最低**能接受多少？” | 钓底价 | “我没有‘最低’这个概念——要说一个数，就是我的期望 20K。”或换口径：“我更愿意说年薪，保底 15 薪下税前 30 万。” |
| “你没经验，我们**一般**给 14K。” | 虚构统计 | “理解起薪有体系。14K 和我的期望还有距离：评级能不能复核？公积金按 12% 还是 5%、基数按实际工资吗？房补随月发吗？” |
| “我们**统一标准**，其他 27 届都是这个数，没有议价空间。” | 社会压力话术 | “理解，月薪统一我尊重。那这个岗位的 22K 是按什么标准给的？”然后把战场移到统一表以外的项 |
| “22K 是给有经验/硕博的，**本科到不了**。” | 无法核实的上限 | 把“经验”翻译成“能力”：用项目自证（端到端落地、Agent 工具调用），要求**按能力评级** |
| “我帮你申请，但可能性不大，**你先给个答复时间**” | 用不确定的让步换你确定的承诺 | “想问申请多久有结果？我这边需要 5 个工作日——在跟另外的流程，也要和家里商量。能不能先把书面 offer 发我？” |
| “offer 只有 3 天有效，过期释放给候选池” | 期限压力 | 确认起算点（3 个工作日 vs 3 天）、低成本试一次延长、接受就换信息（书面 offer + 公积金基数），别卡最后一小时 |
| “你还有什么想问的吗？” | 最后一次影响定档 | 问定档/评级/公积金基数/补贴发放方式；不问“发展前景”、不闲聊 |
| “你有其他 offer 吗？” | 探你的杠杆 | 有就如实说区间；没有就说“有几家在流程中，还在早期”——**不编**（会被要求出示） |

## 3. 公积金三层（他会追问“这也能谈吗”）

| 层 | 能不能动 | 怎么用 |
|---|---|---|
| 比例 | **基本不能**：法定 5%–12%、单位自主确定、同单位统一、按年调整 | 承认它，别死磕 |
| 基数 | **能提**：应按实际工资 | “基数按实际工资还是最低基数？”（比例 5% + 按最低基数 = 明显吃亏） |
| 差额折算 | **正确打法** | 把比例差额折成月薪/补贴：“比例统一我理解，但这一项我一年差 1.3 万，月薪能不能补一点？” |

**算例（14K×15、杭州、含租房扣除）**：公积金 12% → 到手 16.55 万/年 + 公积金账户 4.03 万；公积金 5% → 到手 17.61 万/年 + 账户 1.68 万。到卡每月多 882 元，但一年**净亏 1.29 万**。现算用 `takehome_calc.py`，别心算。

## 4. 期限处理

- **3 天通常能谈到 5–7 天**，问一句被拒 = 零代价；不问 = 白让。
- 先说清起算点，以及是“工作日”还是“自然日”（HR 常混用）。
- 接受期限时顺手换信息（书面 offer、公积金基数）——别白白答应。
- **提前 12 小时回复**，别卡最后一小时（邮件延迟 + 显得是考虑后的决定）。
- 期限期间必须做的事（否则到期只能签）：投同公司 band 更高的岗、投有明确薪数的同类公司、整理项目一页成果摘要、给自己定一个决策日。

## 5. 止损线

月薪改不动、手上又没有更好的机会时：**接受，然后把谈判推迟到每年 4 月/10 月的薪酬复核窗口**。
不要为一项改不动的条款赌掉唯一 offer。**谈判目标是“别被压到底”，不是“每项都赢”。**

## 6. 他的反应模式（教学注意）

- 中途追问机制（“公积金这也能谈吗”“有规定吧”）→ 先给规则边界表，再给话术。
- 给“对一半”的判断 → 明说「对了一半」，先肯定再纠正另一半。
- 写「不会」→ 直接给答案 + 讲透，不反复引导。
- 单行短答 → 判分逐题来，一次只问一题。
