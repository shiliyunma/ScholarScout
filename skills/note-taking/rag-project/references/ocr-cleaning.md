# OCR 文本清洗 — 原理与局限

## 适用场景

中文教材/文档经 OCR 后产生的常见垃圾字符清洗方案。

## 清洗层次

### 第一层：规则清洗（推荐，0 成本，去 80%）

| 规则 | 示例 |
|------|------|
| 去除不可见控制字符 | `\x00-\x08` `\x0b\x0c\x0e-\x1f` |
| 压缩重复标点 | `。。。` → `。` `————` → `——` |
| 去除孤立噪音符号 | `§©®` 等不在保留字符集中的字符 |
| 压缩中文内部多余空格 | `人 工智 能` → `人工智能` |
| 保留英文单词间空格 | `Machine Learning` 不受影响 |
| 清理行首行尾空白 | `  hello  ` → `hello` |

保留字符集：中文、日文假名、英文、数字、基本标点、括号、引号、书名号、`+/%=#@_`、换行缩进。

### 第二层：LLM 精修（可选，花 token，去 95%）

- 修正形近字：`伸仲` → `伸`，`α` → `a`
- 修复断词：`机 器学 习` → `机器学习`
- 去除语义级乱码
- 风险：prompt 约束不够严时，LLM 可能重写内容

## 已知局限（规则清洗清不掉的）

1. 形近字（`延仲` → 应是`延伸`）—— 需要语义理解
2. 一整行 OCR 完全识别成乱码的文本 —— 没有可识别模式
3. 英文/数字混入中文标点 —— `Leαrning` 中的希腊字母 `α`

## scripts/clean_ocr.py 用法

```bash
# 预览改动（不写入）
python scripts/clean_ocr.py --dry-run

# 输出到另一目录（保留原文件）
python scripts/clean_ocr.py --output clean_docs

# 原位覆盖 docs/*.txt
python scripts/clean_ocr.py
```

输出附汇总：处理文件数、总字符数变化、移除字数和百分比。
