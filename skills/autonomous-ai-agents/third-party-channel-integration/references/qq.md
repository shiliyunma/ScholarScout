# QQ 渠道（QQ 机器人开放平台 / bot.q.qq.com）

**证据等级**：以下为**官方文档页面原文**（bot.q.qq.com/wiki）逐条核过；标"据目录推断"的不是平台承诺。

## 连接方式

- 官方机器人 v2：**WebSocket 长连接入站**（Identify 报文里带 `intents` 位掩码声明要收哪些事件）
  + **REST 出站** → **不需要公网地址**。
- `intents` 是**建连时声明**的（不是后台申请）；但部分 intent 受权限限制，改了连不上：
  错误码 **4013 无效 intent** / **4014 intent 无权限** / **4914 机器人已下架只允许沙箱** / **4915 已封禁**。

## 凭据

- `QQ_APP_ID` / `QQ_CLIENT_SECRET`，来自 **q.qq.com 管理端**（或扫码绑定，secret 需 AES 解密）。
- 依赖：`aiohttp` + `httpx`（收消息必须有 WS 客户端；**只做出站私聊推送则不需要**）。

## 只能人工的步骤

1. 登录 q.qq.com **认证主体** → 管理端建机器人 → 拿 AppID/Secret；
2. 设"使用的范围"（未认证：仅管理员自己当群主的群；个人认证：可公开、进群上限 **500**；企业认证：全场景）；
3. **拉机器人进群没有 API** —— 官方路径是**升级到最新版移动 QQ，由群主/管理员手动添加**；
   API 侧只有 `POST /v2/generate_url_link`（生成分享链接，官方用途写的是"邀请用户添加机器人为好友"）
   和 `GET /v2/groups/{group_openid}/bot_state`；不在群里发消息回 **40034101 / 40054003**（机器人非群成员）。
4. **群主动消息不是后台填工单**，而是**群主在 QQ 客户端里点机器人开"主动推送消息能力"**
   （群里 @ 不回复、私聊可以，就是这个开关没开）→ 未授权回 **40034105**。
   （官方另一处又提到主动消息有"审核"、可用 `MESSAGE_AUDIT` 事件取结果 —— **两条口径未对齐，按"可能还有审核"保守处理**）。

## 配额（写功能前先算）

- 群主动消息：**Bot 维度**企业/个人认证 60 qpm、未认证 30 qpm；单关系 20 qpm；**每群每天上限 1000 条**。
- **被动回复**：有效期 **5 分钟**、每条消息最多回复 **5 次**。
- 其他：40034100 主动消息超频控；40034027 该事件不支持回复；40034128 被动回复时间/次数超限。

## 群标识（关键）

- `group_openid` **只能从群消息事件里带回来**（`GROUP_AT_MESSAGE_CREATE` / `GROUP_MESSAGE_CREATE`），
  发送用 `POST /v2/groups/{group_openid}/messages`。
- **官方没有"机器人群列表"接口**（"机器人"分组只有 `users/@me`、`users/@me/guilds`（**频道**列表）、生成分享链接）
  —— **据官方文档侧边栏目录推断**，不是明文承诺。
  → 设计含义：**群台账只能"第一次收到该群消息时登记"**，做不到"一次拉全"。

## 群消息触发

- 入站默认只带 **@机器人** 的群消息（`GROUP_AT_MESSAGE_CREATE`），另有全量 `GROUP_MESSAGE_CREATE`（受权限门控）。
