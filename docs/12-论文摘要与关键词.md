# 论文摘要与关键词

## 中文摘要

针对进入陌生研究方向时"资料散落、来源不可追溯、成本不透明、读完记不住"的问题，
本文设计并实现了一个**桌面级、全本地的学习辅助调研智能体 ScholarScout**。
系统以一句方向描述为输入，在开放世界中检索真实资料（学术、代码与教程、通用三层共 12 个来源适配器，
其中 4 个免密钥可用），抓取正文并生成结构化摘要，进而产出方向知识地图与学习路线，
并在用户明确要求时生成抽背卡；全部数据落在本机 SQLite 与文件系统中，双击即用。

本文的重点不在功能堆叠，而在**把结论变成可复算的数字**：

（1）**两级反幻觉度量**：守卫只校验"引用是否真实"（给出可归属率），
另设引用语义支持度校验回答"被引资料是否真的支持该断言"，并**按证据等级分层报告**；
（2）**成本账单解剖**：实测每轮固定重发约 1,956 tokens、一轮对话约 10 次模型调用，
逐项量化各杠杆收益，并明确记录"测量后判定不做"的优化项。

实验结果表明：判权分层一致率 **100%**（κ=1.000）、误升率 0%；
关闭守卫会使出处覆盖率从 76.9% **虚高到 92.6%**；端到端 6 题出处覆盖率 **100%**（153/153）、
ungrounded 0%、降级率 0%；引用语义支持度在 23 条可复核样本上为知识地图 **91.7%**、
学习路线 **90.9%**，分层后**强证据（有摘要）8/8 = 100%、弱证据（仅标题）93.3%**；
产物按需生成在探针题集上"题面未要求却生成"为 **0%（0/3）**、结尾主动询问 100%；
上下文瘦身使同题输入 token 下降 **15%**。系统规模为后端 72 个文件 11,127 行、
测试 712 项、数据库迁移 6 个。

本文同时如实报告局限：评测样本量小（不作统计显著性主张）、
语义支持度为**模型判定而非人工金标准**、扫描版 PDF 正文抽取未端到端验证成功、
全部实测在单一机器与单一模型档位上完成。

**关键词**：学术调研智能体；检索增强生成；引用可核查与反幻觉；成本控制；学习路径生成

## Abstract

To address the problems of scattered materials, untraceable sources, opaque cost, and poor retention
when a learner enters an unfamiliar research direction, this thesis designs and implements
**ScholarScout**, a desktop-level, fully local research-and-learning assistant agent.
Given a one-sentence direction description, the system searches the open world for real materials
(academic, code/tutorial, and general layers; 12 source adapters, 4 of which are key-free),
fetches and summarizes full texts, and then produces a knowledge map and a learning route,
generating flashcards only when the user explicitly asks for them.
All data lives in a local SQLite database and file system, and the application starts with a double click.

The contribution is not feature accumulation but **turning claims into recomputable numbers**:

(1) **two-level anti-hallucination measurement**: a guard verifies only that citations are *real*
(yielding an attributable rate), while a separate semantic-support check answers whether the cited
material actually *supports* the claim, reported **in strata by evidence level**;
(2) **cost anatomy**: measurement shows a fixed per-round resend of about 1,956 tokens and
about 10 model calls per turn; each lever's gain is quantified, and one optimization that was
measured and then **deliberately rejected** is documented.

Results: tier classification agreement is **100%** (κ=1.000) with a 0% over-promotion rate;
disabling the guard inflates the citation coverage from 76.9% to **92.6%**;
the end-to-end set achieves **100%** coverage (153/153), 0% ungrounded and 0% degradation;
semantic support on 23 reviewable samples is **91.7%** (knowledge map) and **90.9%** (learning route),
and **100% (8/8) on strong-evidence samples** versus 93.3% on weak-evidence ones;
on the probe set, unauthorized artifact generation is **0% (0/3)** with 100% explicit follow-up asking;
context trimming reduces input tokens by **15%** on the same task.
The system comprises 72 backend files / 11,127 lines, 712 tests, and 6 database migrations.

Limitations are reported honestly: small sample sizes (no statistical significance claimed),
semantic support evaluated by a model rather than human gold standard, end-to-end validation of
scanned-PDF extraction not achieved, and all experiments on a single machine and a single model tier.

**Keywords**: research assistant agent; retrieval-augmented generation; citation verifiability and
anti-hallucination; cost control; learning path generation
