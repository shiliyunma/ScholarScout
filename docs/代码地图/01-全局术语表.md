# 全局术语表（唯一副本，别在子目录里另写一份）

> 为什么**只有一份**：同一个术语会横跨很多目录 —— 实测 `source_id` 出现在 8 个 `src/scholarscout/`
> 子目录、`tier` 6 个、`relevance` 5 个。按目录各写一份 = 同一个词解释 8 遍、改一处同步 8 处。
> Chromium《Documentation Best Practices》把这条列为 **"Duplication is evil ... Link to it instead."**
>
> "出现在哪些目录"一列是**脚本量出来的**（`src/scholarscout/` 下含该符号的子目录），不是印象。
> 它会随代码变 —— 需要刷新时重跑本文件末尾那条命令。

## 刷新"出现在哪些目录"这列

```bash
cd "D:/AI+教育毕设毕设/ScholarScout"
.venv/Scripts/python.exe - <<'PY'
import pathlib
terms = {"source_id":"source_id","tier":"tier","relevance":"relevance","guard":"guard",
         "authority":"authority","trace":"tool_traces","ToolSpec":"ToolSpec",
         "FTS5":"fts5","trigram":"trigram"}
dirs = [d for d in pathlib.Path("src").rglob("*") if d.is_dir() and d.name != "__pycache__"]
for label, needle in terms.items():
    hit = sorted({d.relative_to("src/scholarscout").as_posix() for d in dirs
                  if any(needle.lower() in f.read_text(encoding="utf-8", errors="ignore").lower()
                         for f in d.glob("*.py"))})
    print(f"| {label} | {len(hit)} | {'、'.join(hit)} |")
PY
```
