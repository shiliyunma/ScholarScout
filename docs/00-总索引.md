## 5. 开工顺序（冻结后）

```
M1 骨架与存储   state/ 建库 + cjk 切分 + FTS 触发器 + 契约测试（能存能搜，不接模型）
M2 桌面壳与人机桥  rpc/ + pywebview 壳 + 会话落库（能对话，工具还是假的）
M3 检索引擎     fetch/http.py + arxiv/openalex/s2 + research.search（真的能找到资料）
M4 判权与归档   grading/ + source.fetch + source.grade（能找到、能判、能归档）
M5 学习产物     topic.build_map + route.plan + note.save
M6 评测与论文   eval/ + 指标 + 对照实验
```

每个 M 的完成标准只有一个：**`bash scripts/check.sh` 全绿 + 该 M 的契约测试通过**。
