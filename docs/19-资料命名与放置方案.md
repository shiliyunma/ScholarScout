# 19 抓取资料的命名与放置（人类可读方案）

> 状态：**已实现并已在真库迁移完成（2026-10-11）**。
> 目标：打开 `data/` 就能看懂 —— 文件名是**资料自己的标题**，目录按**类型/年-月**分桶；同时不破坏
> 既有的去重、可回溯、正文不入库等约束。

## 0. 三条不能破的前提

1. **sha256 仍是去重与不可变的锚**（`documents.sha256` 保留）；文件名可以变，**锚不能丢**。
2. **一份资料可属于多个主题/多次调研** → **不按主题放文件**；主题关系走索引与资料库分组。
3. **正文不入库**：库里只有元数据+摘要+路径；全文落 `data/text/`，原件落 `data/raw/`。

## 1. 命名规则（原件与全文同名，只换后缀）

```
<标题 slug>--<sha8>.<ext>
```

- **标题来源**：优先资料真实标题（arXiv 标题 / 页面 `<title>` / PDF 元数据）；
  - 取不到标题时降级为 `<域名>--<sha8>.<ext>`（**不编标题**）。
- **slug 规则**（`paths.slugify`）：
  - 去掉 Windows 非法字符 `< > : " / \ | ? *` 与控制字符（0x00–0x1f 与 DEL）；
  - 空白与下划线 → `-`；连续 `-` 合并；首尾 `-`（以及尾随 `. `）去掉；
  - **保留中英文**（可读性优先），不做拼音化；
  - **长度上限 60 字符**（按字符计，中英一视同仁），超出则截到 59 再补 `~`（**含 `~` 仍不超过上限**）；
  - 空 slug 时回落到 `<域名>`（都空则 `untitled`）。
- **`--<sha8>` 后缀**：取 `sha256` 前 8 位 —— 保证同名不同文**不冲突**、删了索引也能回溯到唯一原件。
- 例：`data/raw/paper/2024-10/pi0-A-Vision-Language-Action-Flow-Model--ac4d3d6e.pdf`

## 2. 放置（按类型/年-月分桶，未知单列）

```
data/raw/<类型>/<年-月>/<标题>--<sha8>.<ext>
data/text/<类型>/<年-月>/<标题>--<sha8>.txt
data/library/<类型>/<年-月>/index.md     # 该桶的清单
data/library/index.md                    # 全库总清单
```

- **类型**取自 `sources.source_type`，由 `paths.doc_type_for` 映射：`arxiv`/`openalex`/`semantic_scholar`/`doi` → `paper`、
  `github` → `code`、`official`/`web` → `doc`、`video` → `video`；认不出来 → `other`（**不编类型**）。
- **年-月**取自资料自己的时间戳，由 `library.naming.year_month_for` 推：优先 arXiv 号自带的 `YYMM`
  （`2410.24164` → `2024-10`）、再看 meta 里的发表/更新日期；**推不出来一律落 `unknown/`**，
  绝不用抓取日期冒充发表日期（与 `docs/05`「未知年份不编」同口径）。
- `index.md` 每行：标题 ｜ 年-月 ｜ 类型 ｜ 来源域 ｜ 关联主题（会话标题）｜ 相对路径。
  主题可多个，用 `、` 分隔 —— 这样"一份资料属于多个主题"既看得见、又不必搬文件。
  索引由 `library.index.render_index`（**纯函数**）渲染，界面 `archive.reindex` 与迁移脚本共用同一份，逐字节一致。

## 3. 迁移历史文件（一次性，**已跑完**；可重跑）

`scripts/migrate_raw_names.py`（真库已执行：**改名 41 ｜ 跳过 0 ｜ 冲突 0 ｜ 失败 0**）：

1. `--dry-run` 先打印"旧路径 → 新路径"清单与冲突数，**不动任何文件**；
2. 正式跑：按 `documents` 表逐条 `rename`（原件与全文各一次），**在同一个事务里**更新
   `raw_path` / `text_path`；库更新失败就把文件改回去并如实报告（不留"库里说在这、盘上在别处"的错位）；
3. **幂等**：新名与库里现有路径逐字符一致就 `skip`（重跑 = 全部跳过）；
4. 冲突（目标已被别的文件占用、且不是同一个文件）：给新名追加 `--2`、`--3`…，在报告里单列；
5. **全部迁移**：不区分新旧，库里每条 `documents` 都按新口径重算一遍路径；
6. 结束打印：改名数 / 跳过数 / 冲突数 / 失败数（失败逐条给原因，不静默）。

**旧目录清理与 `_orphan/` 策略**（`library.migrate._cleanup_old_dirs`）：

- 迁移后把 `data/raw/<2位>/`、`data/text/` 顶层**未被库引用的**历史文件移进 `data/raw/_orphan/`、
  `data/text/_orphan/`（**隔离而非删除** —— 那些文件已无元数据、编不出人类可读的名字，删了就是数据丢失）；
- 计划涉及的任何路径（含失败后留在原地的旧路径）都受保护，不会被误当孤儿；
- 空掉的 `<2位>` 目录随即删除（真库已清空并删除）。

## 5. 测试（全桩测）

- `slugify`：非法字符、空白/下划线、连续 `-`、中英混排、超长截断、空标题回落；
- 路径拼装：类型/年份/未知年份桶、同名不同 sha 不冲突、超长路径不触发 Windows 260 限制；
- 迁移：`--dry-run` 不落盘、正式跑后 DB 路径与磁盘一致、重跑幂等、冲突追加 `--2` 并报告；
- 索引：多主题用 `、` 分隔、未知年份单列、空库不报错。

## 6. 明确不改的

- 不按主题移动文件；不做拼音化；不引入新依赖；不改 `sha256` 去重逻辑；
- 不把摘要/正文塞进文件名以外的任何新地方（正文照旧不入库）。

## 7. 需要用户点头的三处默认（都已选好，可否决）

1. **目录分桶**：`类型/年-月`（备选：扁平放 `data/raw/` 一层）；
2. **标题长度上限 60 字符**（保护 Windows 路径；超出用 `~` 截尾）；
3. **历史文件也一起迁**（备选：只对以后新抓的生效，老文件不动）。
