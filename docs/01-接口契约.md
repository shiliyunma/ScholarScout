## 1. 分层与调用方向（单向，不许反向）

```
┌──────────────────────────────────────────────────────────────┐
│ 桌面壳  pywebview (Edge WebView2)                             │
│   ui/index.html + app.js  —— 只发 JSON-RPC，不读库、不发外网   │
└───────────────────────────┬──────────────────────────────────┘
                            │ JSON-RPC 2.0 over stdio (UTF-8, 一行一消息)
┌───────────────────────────▼──────────────────────────────────┐
│ rpc/server.py  —— 方法表 + 参数校验 + 流式通知                 │
└───────────────────────────┬──────────────────────────────────┘
                            │ 进程内函数调用
┌───────────────────────────▼──────────────────────────────────┐
│ runtime/  单轮 loop：组装上下文 → 调模型 → 执行工具 → 落 trace │
│   registry.py（工具注册表） context.py（会话上下文）           │
└───────────┬───────────────────────────────┬──────────────────┘
            │ 模型可见工具                   │ 读写
┌───────────▼──────────────┐    ┌───────────▼──────────────────┐
│ tools/*.py（6 主线 + 1 降级）│    │ state/db.py（SQLite + FTS5） │
└───────────┬──────────────┘    └──────────────────────────────┘
            │ 只经此层出网
┌───────────▼──────────────────────────────────────────────────┐
│ providers/*（arxiv/openalex/s2/web/github/llm）               │
│ fetch/http.py —— 统一限速 / 退避 / 缓存 / UA / 超时           │
│ data/raw/ 原件 ｜ data/text/ 纯文本 ｜ data/cache/ 抓取缓存    │
└──────────────────────────────────────────────────────────────┘
```

三条硬规则：

1. **前端只调 RPC**：不直接读 SQLite、不直接发 HTTP。单入口才可能把每次调用记进 `tool_traces`，指标才是真数。
2. **模型只看得见 `tools/`**：加能力 = 加一个工具或一个 provider，不许在 loop 里塞特例分支。
3. **出网只走 `fetch/http.py`**：限速、退避、缓存、UA 全在这一处；绕过它的请求在 review 里直接打回。

## 2. JSON-RPC 2.0 传输层

- 传输：**stdio**，一行一个 JSON 对象，UTF-8 **无 BOM**
- 版本：JSON-RPC 2.0；**通知**（无 `id`）用于流式事件
- 启动顺序：壳启动 → 拉起 `python -m scholarscout --rpc` → 调 `system.health` 自检 → 调 `session.list` 渲染侧栏
- 错误码：

| code | 含义 |
|---|---|
| -32700 / -32600 / -32601 / -32602 / -32603 | JSON-RPC 标准（解析/请求/方法不存在/参数非法/内部错误） |
| -32000 | 未登录或未配置模型（缺 API key） |
| -32001 | 外部服务不可用（arXiv/S2 挂了或限速中） |
| -32002 | 资源不存在（source_id / doc_id 查不到） |
| -32003 | 抓取被拒（403/429/robots） |
| -32004 | 超时 |
| -32005 | 取消（用户点了停止） |

## 4. 流式事件（notification）

| 事件 | 载荷 |
|---|---|
| `chat.delta` | `{turn_id, seq, kind:"text"\|"thinking", text}` |
| `chat.tool_call` | `{turn_id, seq, call_id, tool, args_digest, args_preview}` |
| `chat.tool_result` | `{turn_id, seq, call_id, ok, digest, latency_ms, refs}` |
| `chat.done` | `{turn_id, stop_reason, usage:{prompt_tokens, completion_tokens}}` |
| `chat.error` | `{turn_id, code, message}` |

`stop_reason` 取值固定：`completed` | `tool_limit` | `cancelled` | `error` | `refused`。
（`tool_limit` 必须存在：小模型不调工具与死循环都要能区分，这是踩过的坑。）

## 5. 工具契约（模型可见）

### 5.0 通用约定

- 命名：`namespace.action`，namespace ∈ `{research, source, topic, route, note, kb}`
- 每个工具 = `ToolSpec{name, description, parameters(JSON Schema), handler, toolset}`
- JSON Schema 一律 `additionalProperties: false`，参数校验失败 → `-32602`
- **返回统一包络**（这是可追溯性的根）：

```json
{
  "ok": true,
  "data": { },
  "error": null,
  "refs": {"source_ids": [], "doc_ids": [], "chunk_ids": [], "note_ids": [], "route_ids": []}
}
```

> 规则：**任何进入回答的 id 必须回填 `refs`**。回答里写了没回填的 id，等于假引用 —— 评测里算错，答辩时算失信。

- 所有工具调用落 `tool_traces`（名字、args 摘要、结果摘要、时延、成败）
- `toolset` 取值：`research`（默认开）｜ `kb`（默认关，消融开关）

### 5.1 `research.search`

```
input : {query: str, sources?: ["arxiv","openalex","semantic_scholar","web","github"],
         limit?: int = 10, year_from?: int, sort?: "relevance"|"date", lang?: "zh"|"en"}
output: {items: [source_card], provider_status: [{provider, ok, n, error?}]}
```

`source_card`：

```json
{"source_id":"src_xxx","title":"…","url":"…","domain":"arxiv.org","authors":["…"],
 "year":2025,"venue":"NeurIPS","source_type":"arxiv","tier":1,"tier_label":"一手权威",
 "score":0.82,"snippet":"…","has_full_text":true}
```

- **必须落库后才返回 `source_id`**；同一 URL 复用既有 id（`sources.url_canonical` 唯一约束保证）
- 每个 provider 独立限速；某个 provider 失败**不阻塞**其他，只在 `provider_status` 里标红

### 5.2 `source.fetch`

```
input : {url?: str, source_id?: str, want?: ["text","html","pdf"], force?: bool = false}
output: {doc_id, source_id, mime, chars, lang, raw_path, extract_status, summary?}
```

- 原件落 `data/raw/<sha256[:2]>/<sha256>.<ext>`；纯文本副本落 `data/text/<doc_id>.txt`
- 去重顺序：`sha256` → `ETag`/`Last-Modified` → 命中即回，不重抓
- `extract_status` ∈ `ok` | `no_text_layer`（扫描件，记 `documents.ok=0`）| `too_large` | `blocked`
- 正文按 `config.chunk.max_chars` 切块写 `doc_chunks`（含 `text_seg`），**引用可定位到块**

### 5.3 `source.grade`（"判断权威性 / 判断相关性"的落点）

```
input : {source_ids: [str]} 或 {urls: [str]}
output: {items: [{source_id, tier, tier_label, authority, relevance,
                  signals: [{name, weight, value}], verdict, reason}]}
```

- `verdict` ∈ `核心` | `相关` | `外围` | `排除`
- **authority 由规则表 `source_tier_rules` 判定，不由模型拍脑袋** —— 可解释、可复现，论文里能算一致率
- **relevance 才交给模型**，且必须给 `signals`（命中了哪些关键词/哪个 tier/哪一年）与 `reason`
- 结果落 `sources.tier/authority` + `summaries(kind='why_relevant')`

### 5.4 `topic.build_map`

```
input : {topic: str, source_ids?: [str], max_nodes?: int = 30}
output: {topic_id, nodes: [{nid, label, kind, source_ids}], edges: [{src, dst, rel}]}
```

- `kind` ∈ `concept` | `method` | `dataset` | `tool` | `venue`
- `rel` ∈ `prerequisite` | `variant` | `uses` | `evaluates`
- **每个 node 至少挂 1 个 source_id**（除非标 `"source_ids":[]` 且 `label` 前缀 `[无出处]`，评测里这些算失分）

### 5.5 `route.plan`

```
input : {topic, level: "入门"|"进阶"|"研究", weeks?: int = 4,
         weekly_hours?: int, source_ids?: [str]}
output: {route_id, weeks: [{idx, goal, items: [{kind, title, source_id?, why, est_minutes}],
                            checkpoint}]}
```

- `kind` ∈ `paper` | `doc` | `video` | `code` | `exercise`
- 每个 `item` 必须带 `source_id`（库里已有）或显式 `"source_id": null` + `why` 里说明是自生成
- `checkpoint` 是"能回答什么/能做出什么"，不是"学完这一章"

### 5.6 `note.save`

```
input : {kind: "summary"|"note"|"card", title: str, content: str,
         refs?: {source_ids?, doc_ids?, chunk_ids?, session_id?}, tags?: [str]}
output: {note_id, path}
```

### 5.7 `kb.search`（**降级通道 / 消融开关，默认关**）

```
input : {query: str, k?: int = 5}
output: {items: [{chunk_id, text, score}]}
```

- 只在 `toolsets` 含 `kb` 时注册；`config.ENABLE_KB=0` 整批关掉
- 用途：论文消融对照（回答"开放世界方案为什么不需要自建知识库"），不是主线功能
