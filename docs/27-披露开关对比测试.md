# 27 · 渐进披露开关 A/B 对比（n=2 方向性结果）

> **一句话**：披露把每轮的**上下文账单**压掉了 41%（11 141 → 6 545 字符），但在这次 2 个对话 6 轮里，
> **调用总数与冗余都变多了**（19 → 25 次；14 → 19 次），逐轮工具名准确率（TCA-name）两组都是 0。
> 即：**省 token 是确定的，省调用没被这次样本支持**。n=2，只能当方向，不是定论。

口径：`eval/run_dialogues.py --live --limit 2`（只跑 c1、c2，共 6 轮），指标定义见 `eval/dialogue_metrics.py`
（`tool_call_accuracy(match="name")` = 逐轮工具名集合**完全相等**才算对；`redundant_calls` = Σ 每轮 max(0, 实际 − gold)）。

## 一、开关怎么切的（证据）

| 项 | 做法 |
| --- | --- |
| 代码基线 | `git archive dd0caa8`（当时 HEAD）导出到临时目录，**两组跑同一份代码** |
| 配置切换 | 只改临时快照里的 `config.yaml`，新增 `features:` 段：A `enable_tool_disclosure: false`、B `true`；两组的 `enable_files` 都是 `false`（HEAD 默认），把变量锁在一个开关上 |
| 其它条件 | 同一模型 `deepseek-flash`、同一份 `.env`（复制进快照，全程未打印密钥）、同一份 `prompts/`（快照自带 17 个 md） |
| 数据隔离 | 两份报告都记 `db_mode = temporary (paths.isolated_home)`；跑前/跑后仓库 `data/raw` 都是 **91** 个文件；`run/state.db` mtime 未变（10-24 22:13） |
| 报告位置 | 临时目录 `%LOCALAPPDATA%\Temp\scs-ab-pin\{a,b}-reports`，**没有**写进仓库 `eval/reports` |

为什么用 HEAD 快照而不是工作区：测量期间工作区被**另一个会话并发修改**（`git status` 从 0 个改动变成 13 个 M，
其中包括把两个特性开关的默认值改成 `true`、把 `file.list` / `file.read` 加进 `CORE_TOOLS`）。
拿工作区跑会让两组落在不同代码状态上，A/B 就不成立了 —— 所以两组都固定在 `dd0caa8`。

其中 5 次检索、1 次被判重闸拒掉）。

## 四、结论（四条）

1. **调用总数：多了，不是少了。** 19 → 25（+32%）。"披露能降低模型每轮多做无用调用"这条假设，
   在这次 n=2 的样本里**没有被支持**。
2. **冗余：也多了。** 14 → 19。多出的部分可以逐次归因：4 次元工具（先查后用本来就要付的钱）+ 2 次首轮多发检索；
   冗余的成因是"首轮想一次铺开搜索/取原文"，不是"工具名太多导致选错" —— A 组首轮同样 6 次调用，只比 gold 多 5 次。
3. **没有闸卡死的迹象。** B 组 `tool_not_loaded` **0 次**、0 轮空轨迹（反倒是 A 组 c2 第 3 轮一次都没调）；
   c1 第 2、3 轮能看到正确路径 `tool.search` → `tool.describe` → 直调 `source.grade` / `topic.build_map`，
   说明闸的语义被模型照做了，披露不是"卡住模型"的那类改动。
4. **省的是上下文，不是调用。** payload 11 141 → 6 545 字符（−41%）、声明工具 11 → 5，这是确定性收益；
   但 TCA-name 两组都是 0，说明在这套指标下"工具名集合完全相等"主要由首轮过度调用决定，
   把声明从 11 个裁到 5 个并没有把准确率抬起来。要让披露兑现成"更少调用"，
   下一步得动的是**首轮的调用预算/流程约束**（如首轮限 1 search），不是工具声明的数量。

## 五、限制（读结论前必看）

- **n=2 个对话、6 轮、单次试验（pass^1）**：模型有随机性，±3 次调用的波动就足以翻转"多/少"的方向；
  本文只能当**方向性观察**，不能当定论。要定论需要 `--limit 6` 全量 + 每组多次重复（pass^k）。
- **外生噪声**：`research.search` 的判重闸在 B 组触发过一次（"与本会话已搜过的高度重复"），
  检索源返回与网络状态在两组不完全一致；A 组 c2 也触发过一次。
- **测量对象是快照，不是当前工作区**：测量期间另一会话正在改这套代码
  （披露与文件工具的默认值改成 `true`、`CORE_TOOLS` 扩到 5 个）。当前工作区的行为已与本文不同，
  本文的结论**只对 `dd0caa8` 成立**，不外推到那些改动。
- 提示词/payload 字符数是**离线确定性**测量（同一快照、同一 `research` 工具集、`enable_kb/enable_files` 均关），
  不依赖模型，可复算；调用类指标依赖真实模型与网络，不可逐字复现（`docs/05 §3`：E4 不进门槛）。
