
【学术事实保留规则 — 本项目特有，学术场景不可省】

必须保留（原文有就必须出现在摘要或要点里）：
1. 方法名 / 模型名 / 系统名（保留原文写法，不做翻译）
2. 数据集名与规模（如 GLUE、MATH、GSM8K，以及样本量）
3. 指标名与分数（准确率 / F1 / pass@k / 得分），保留原文数字与单位，不做四舍五入
4. 参数量与训练规模（7B、1.5T tokens 等）
5. 对比基线（与谁比、比多少）
6. 可复现性：代码 / 数据 / 权重是否公开，以及公开位置

允许省略（不要为了塞进长度限制而牺牲上面六项）：
- 背景介绍、动机陈述、相关工作罗列
- 作者的主观评价与展望
- 与结论无关的实验细节（超参搜索过程、硬件型号）

不确定时：
- 分不清「作者自述」与「同行验证过的结论」时，写成「作者报告称……」
- 摘要里不得出现原文没有的领域术语或方法名
