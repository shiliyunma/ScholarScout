## 1. 这个目录放什么

把"系统能不能用"变成**可复算的数字**：

- **题集**：`sets/` —— `e1_grade.jsonl`（判权）、`e2_guard.jsonl`（守卫）、`e3_tasks.jsonl`
  （端到端）、`e3_probe_tasks.jsonl`（只要回答、不要产物的探针题）、`e4_dialogues.jsonl`
  （**E4 多轮对话**：6 个对话、**合计 15 轮**（逐对话 3/3/3/2/2/2），每个对话带 gold 工具轨迹
  与 1～2 条域外探针；末行 `p1` 是单列的主题黏着度探针，给域内 3 条 / 域外 6 条）。
- **运行器与计分**：`run_eval.py`（跑集）、`metrics.py`（指标纯函数，不碰库、不读文件）、
  `run_dialogues.py`（**E4 运行器**：`--plan` 离线看题面 / `--live` 真跑，走临时库）、
  `dialogue_metrics.py`（**E4 指标纯函数**，工具调用轨迹评分，出处见 `docs` 外的
  `Intent Recognition/08-六对话过程评测方案.md`）、
  `report.py`（渲染成可直接贴进论文的 Markdown）。
- **语义支持度**：`verify_support.py`（判定引用"支不支持该断言"，结果落 `support_checks` 表）。
- **产物**：`reports/` —— `<时间戳>.json`（原始数字，供复算）、`<时间戳>.md`（表格），
  以及 `<时间戳>-support.{md,json}`。
- `__init__.py` 只是包标记（供 `from eval import metrics, report`）。

**能确定的不交给模型判**：E1（本地确定性打分）、E2（模型输出写死在题里）**离线可复现、秒级、无需模型与网络**；
E3（任务集）要**真模型 + 真出网**，结果不可复现，**因此 E3 不进门槛**，只在论文与答辩现场跑
（`docs/05 §2.3 / §6`）。

## 2. 先看哪个文件

1. **`docs/05-评测方案.md`**（不在本目录，但是**口径唯一权威**）—— 先读它，再读代码。
2. **`run_eval.py`** —— 运行器：命令行参数、三套集各跑什么、对照臂怎么跑、报告记录什么。
3. **`metrics.py`** —— 指标怎么算（**分母为 0 返回 `None` 而不是 `0`**："没有样本"与"全错"是两件事）。
4. **`report.py`** —— 报告长什么样（空值显示 `—`；**每个比率都跟分子 / 分母**，便于复算）。
5. **`sets/*.jsonl`** —— 题面与期望值（E1 的期望 `tier`/`verdict`、E2 写死的模型原始输出、E3 的请求）。

## 3. 入口契约（命令行 / 题集文件 / 产物路径 / 不入库约定）

- **`run_eval.py`** 参数：`--set {e1,e2,e3,e3probe,all}`（默认 `all`）、`--live`（跑 E3，需密钥与网络）、
  `--ablation`（跑对照臂）、`--auto-artifacts`（E3 对照臂：每轮自动出产物）、
  `--ask-artifacts`（首轮后追发一条"请生成"，量按需生成成功率）、`--no-thinking`（关深度思考的省钱 A/B）、
  `--out`（默认 `eval/reports`）、`--only`（逗号分隔题号）、`--limit`（最多前 N 题）。
- **`run_dialogues.py`** 参数：`--plan`（离线：只输出题面、gold 轨迹，并校验 gold 参数是否合法）、
  `--live`（真跑，需密钥与网络；**走临时库**，跑完即删）、`--limit`（最多跑前 N 个对话）、
  `--out`（默认 `eval/reports`）。E4 与 E3 同类：**不进门槛**。
- **`verify_support.py`** 参数：`--session` / `--kind {topic_map,route}` / `--id` /
  `--limit`（默认 20）/ `--refresh` / `--dry-run` / `--out` / `--db`。
- **报告不入库**：`eval/reports/` 在 `.gitignore` 里（数字随运行时间变）；论文只引用其中的数字并
  **注明报告文件名**（`docs/05 §6`）。
- **每个比率都能写回分子 / 分母**（`report.py` 的硬规则）—— 报 `0` 与报 `—` 必须分得开。

## 改这个目录之前先知道

- **能确定的不交给模型判**：E1 用 `use_model=false` 的本地确定性打分、E2 用写死的模型输出 ——
  这两套是离线回归护栏；只有 E3 才请模型（`docs/05 §2.1 / §2.3`）。
- **E3 不进门槛**：要网络与密钥，逐次不承诺复现（`temperature=0` 也只降低而不消除波动）。
- **分母口径别混**：资料类（`paper`/`doc`/`video`/`code`）计入出处覆盖 / ungrounded 的分母，
  行动类（`exercise`）不计入、单独报 `exercise_items` —— 把练习算成"无出处"是度量错，
  还会反向逼模型给练习硬挂来源（`docs/05 §3.2`）。
- **版本可追溯**：报告记录每档的 `system_prompt_hash`（系统提示词版本，见 `runtime/prompts.py`），
  摘要 / 判权 / 支持度提示词则把各自的 `prompt_version` 随行落库 ——
  "这两组数字来自哪版提示词"必须能回答（`docs/05 §3.3 / §3.4`）。
- **报告里的失败明细不是装饰**：`failure_summary` 给出"哪个工具 / 报什么错"，
  才能解释工具成功率那行的下降（`docs/05 §3.3.1`）。
